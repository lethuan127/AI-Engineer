# ML Paradigms

How a model learns is determined by **what kind of feedback signal** it gets during training. The four main paradigms:

## 1. Supervised Learning

The model learns from **labeled examples**: input \(x\) paired with the correct output \(y\).

\[
\text{Goal: learn } f(x) \approx y
\]

**Examples:**
- Email → spam / not spam (classification)
- House features → price (regression)
- Image → cat / dog / bird (classification)
- Sentence → sentiment score (regression)

**Pros:** clear objective, well-understood, strong tooling.
**Cons:** needs labeled data, which is expensive to collect.

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression().fit(X_train, y_train)  # learns from (X, y) pairs
```

## 2. Unsupervised Learning

The model learns from **unlabeled data** — only inputs \(x\), no targets. It finds structure on its own.

**Examples:**
- Clustering: group customers by behavior (k-means)
- Dimensionality reduction: compress 1000 features into 2 for visualization (PCA, t-SNE, UMAP)
- Anomaly detection: identify unusual transactions

```python
from sklearn.cluster import KMeans
clusters = KMeans(n_clusters=3).fit_predict(X)  # no labels needed
```

**Pros:** no labels required.
**Cons:** harder to evaluate ("is the clustering good?"), no clear objective.

## 3. Self-Supervised Learning

The model **creates its own labels from the data structure**. This is the secret behind modern LLMs.

**Examples:**
- **Next-token prediction** (GPT-style): given "The cat sat on the ___", predict "mat".
- **Masked language modeling** (BERT-style): given "The [MASK] sat on the mat", predict "cat".
- **Contrastive learning**: pull similar items closer, push different items apart in embedding space (CLIP, SimCLR).

\[
\mathcal{L} = -\sum_t \log P(x_t \mid x_{<t})
\]

This is the loss for next-token prediction — the model is rewarded for assigning high probability to the actual next token.

**Why it's powerful:** the internet has trillions of tokens of "free" training signal. No human labeling needed.

**This is how LLMs are pre-trained.** Section 2 of the main path covers transformers and LLMs in depth.

## 4. Reinforcement Learning (RL)

The model (called an **agent**) learns by **interacting with an environment** and receiving **rewards** for good actions.

\[
\text{Goal: maximize } \mathbb{E}\left[\sum_t \gamma^t r_t\right]
\]

(Expected discounted future reward, where \(\gamma \in [0, 1]\) controls how much the agent values future vs. immediate reward.)

**Examples:**
- Game-playing AI (AlphaGo, Atari)
- Robotics (learning to walk)
- **RLHF (Reinforcement Learning from Human Feedback)** — used to align LLMs (ChatGPT, Claude) with human preferences after pre-training.

```python
state = env.reset()
while not done:
    action = agent.choose(state)
    next_state, reward, done = env.step(action)
    agent.learn(state, action, reward, next_state)
    state = next_state
```

**Pros:** handles sequential decisions, no labels needed (just a reward signal).
**Cons:** sample-inefficient, hard to design rewards, training is unstable.

## How LLMs Combine Paradigms

Modern LLMs use a **multi-stage recipe**:

1. **Self-supervised pre-training** on internet text (next-token prediction).
2. **Supervised fine-tuning (SFT)** on curated instruction-response pairs.
3. **RLHF** (or alternatives like DPO) to align with human preferences.

This combination is why LLMs feel both knowledgeable (from pre-training) and helpful (from SFT + RLHF).

## Quick Decision Guide

| You have... | Use... |
|---|---|
| Labeled (input, output) pairs | Supervised |
| Only inputs, want structure | Unsupervised |
| Massive unlabeled data, want a foundation model | Self-supervised |
| Sequential decisions with reward signal | RL |
| Pre-trained LLM, want to align it | RLHF / DPO |

## Takeaways

- **Supervised** = learn from labels. Most production ML.
- **Unsupervised** = find structure. Clustering, dimensionality reduction.
- **Self-supervised** = create labels from data. Powers LLMs.
- **RL** = learn from rewards. Powers RLHF for LLM alignment.
