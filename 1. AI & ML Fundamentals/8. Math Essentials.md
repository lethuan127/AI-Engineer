# Math Essentials (Light Touch)

You don't need to derive proofs. You need to **read formulas without panic** and recognize what they're doing.

## Philosophy: Read It, Don't Derive It

When you encounter \(\nabla_\theta \mathcal{L}\) or \(\text{softmax}(QK^\top / \sqrt{d_k})V\):

- **Recognize** what it represents.
- **Understand** the *intuition* (gradient = "which way is downhill", attention = "weighted lookup").
- **Don't worry** if you can't derive it from scratch.

That's enough to be a great AI Engineer.

## Linear Algebra (Most Important)

### Vectors

A list of numbers: \(x = [x_1, x_2, ..., x_d] \in \mathbb{R}^d\).

- **Length / norm**: \(\|x\| = \sqrt{\sum x_i^2}\)
- **Dot product**: \(x \cdot y = \sum x_i y_i\) — measures similarity.
- **Cosine similarity**: \(\cos(\theta) = \frac{x \cdot y}{\|x\| \|y\|}\) — direction-only similarity. **Used everywhere in embeddings/RAG.**

```python
import numpy as np
x = np.array([1, 2, 3])
y = np.array([2, 1, 0])
print(x @ y)                                                       # dot product = 4
print(np.dot(x, y) / (np.linalg.norm(x) * np.linalg.norm(y)))      # cosine similarity
```

### Matrices

A 2D array: \(A \in \mathbb{R}^{m \times n}\).

- **Matrix multiplication**: \(C = AB\) where \(C_{ij} = \sum_k A_{ik} B_{kj}\). Most ops in neural nets are matmuls.
- **Transpose**: \(A^\top\) — flip rows / columns.
- **Identity**: \(I\), the "do nothing" matrix.
- **Inverse**: \(A^{-1}\) such that \(A A^{-1} = I\) (when it exists).

### Why It Matters

- **Embeddings are vectors.** RAG retrieval = nearest-neighbor search by cosine similarity.
- **Neural net layers are matrix multiplications** plus a non-linearity: \(h = \sigma(Wx + b)\).
- **Attention is a matmul**: \(QK^\top\) computes pairwise similarities between tokens.

## Probability

### Basics

- **Probability** \(P(A) \in [0, 1]\) — likelihood of event A.
- **Conditional probability**: \(P(A \mid B) = P(A \cap B) / P(B)\) — A given B.
- **Independence**: \(P(A \cap B) = P(A) P(B)\).

### Bayes' Theorem

\[
P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)}
\]

In words: **update your belief about A given new evidence B**. Foundation of Bayesian ML and a useful general-purpose reasoning tool.

### Distributions You'll See

| Distribution | Use |
|---|---|
| **Bernoulli** | Binary outcome (single coin flip) |
| **Categorical** | Multi-class outcome (LLM next-token!) |
| **Gaussian (Normal)** | Continuous values, central limit theorem |
| **Uniform** | Random sampling, initialization |

LLMs output a categorical distribution over the vocabulary — temperature, top-k, top-p sampling are different ways to draw from it.

```python
import numpy as np
logits = np.array([2.0, 1.0, 0.1])
probs = np.exp(logits) / np.sum(np.exp(logits))    # softmax → categorical distribution
sample = np.random.choice(len(probs), p=probs)
```

## Calculus (Tiny Bit)

### Gradients

The gradient \(\nabla f(x)\) is the vector of partial derivatives — points in the direction of steepest ascent.

For training: \(\theta \leftarrow \theta - \eta \nabla \mathcal{L}\) — move opposite to the gradient to reduce loss.

That's the whole intuition. Frameworks (PyTorch, JAX) compute gradients automatically via **autodiff**.

```python
import torch
x = torch.tensor([2.0], requires_grad=True)
y = x ** 2
y.backward()
print(x.grad)    # dy/dx = 2x = 4
```

### Chain Rule (One-Liner)

\[
\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)
\]

This is how backpropagation propagates errors through a deep network. You don't compute it by hand — but understanding "errors flow backward through the chain" is enough.

## Statistics

### Summary Statistics

- **Mean**: average.
- **Variance / Std deviation**: spread.
- **Median**: 50th percentile (robust to outliers).
- **Quantiles**: 25th / 75th percentile, etc.

### Sampling & Inference

- **Population** vs. **sample**: you usually only see a sample.
- **Standard error**: how much the sample mean varies from the true mean.
- **Confidence interval**: range that likely contains the true value.
- **Hypothesis testing**: is the observed difference real or noise?

### A/B Testing Basics

When comparing two models or variants:

- **Null hypothesis**: no difference.
- **p-value**: probability of seeing this difference if null is true.
- **Effect size**: how big is the difference (often more important than p-value).
- **Statistical power**: probability of detecting a real effect.

Use **bootstrapping** as a model-free alternative — easy and assumption-free.

## Information Theory (LLM-Adjacent)

- **Entropy**: \(H(X) = -\sum p_i \log p_i\) — uncertainty in a distribution. Higher = more random.
- **Cross-entropy**: \(H(p, q) = -\sum p_i \log q_i\) — the LLM training loss.
- **KL divergence**: \(D_{KL}(p \| q) = \sum p_i \log(p_i / q_i)\) — how much q differs from p. Used in RLHF / DPO.

## Takeaways

- **Linear algebra**: vectors, dot products, matmul. **Most important for embeddings & neural nets.**
- **Probability**: distributions, Bayes, conditional. **Powers LLM sampling and Bayesian methods.**
- **Calculus**: gradients = "downhill direction." Autodiff handles the details.
- **Statistics**: summary stats, sampling, A/B testing. **Daily ML tooling.**
- **Information theory**: entropy & cross-entropy. **The LLM training loss is here.**

## Quick Self-Check

You're ready for AI engineering math when you can:

- Read \(\hat{y} = \sigma(Wx + b)\) and know it's logistic regression.
- See \(\cos(\theta) = (x \cdot y) / (\|x\| \|y\|)\) and know it's similarity.
- See \(\text{softmax}(QK^\top / \sqrt{d_k}) V\) and recognize it as attention.
- See \(-\sum p \log q\) and know it's cross-entropy.

If yes, you're set.
