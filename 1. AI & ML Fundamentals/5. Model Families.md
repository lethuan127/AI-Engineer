# Model Families

A field guide to common model types. For each: one-line intuition, when to use it, and a code snippet.

## Linear / Logistic Regression

The simplest, most interpretable models. **Always your first baseline.**

- **Linear regression**: predict a continuous number.
  \[ \hat{y} = w^\top x + b \]
- **Logistic regression**: predict a probability for binary classification.
  \[ \hat{y} = \sigma(w^\top x + b) = \frac{1}{1 + e^{-(w^\top x + b)}} \]

```python
from sklearn.linear_model import LogisticRegression
model = LogisticRegression().fit(X_train, y_train)
```

**Use when:** small dataset, need interpretability, baseline.

## Decision Trees

A flowchart of if/else splits.

```
        Age > 30?
        /       \
      Yes        No
      /           \
  Income > 50k?   "Class B"
   /      \
 "A"      "B"
```

**Pros:** interpretable, handles non-linear data, no scaling needed.
**Cons:** unstable, overfits easily on its own.

## Random Forests

Average many decision trees, each trained on a random subset. Reduces variance.

```python
from sklearn.ensemble import RandomForestClassifier
model = RandomForestClassifier(n_estimators=100).fit(X_train, y_train)
```

**Use when:** tabular data, want strong baseline with little tuning.

## Gradient Boosting (XGBoost / LightGBM / CatBoost)

Sequentially train trees that each correct the previous's mistakes. **Often the best model on tabular data** (Kaggle's favorite).

```python
import xgboost as xgb
model = xgb.XGBClassifier().fit(X_train, y_train)
```

**Use when:** you have tabular / structured data and want maximum accuracy.

## Neural Networks (MLPs)

Stacked layers of weighted sums + non-linearity (e.g., ReLU).

\[ h_1 = \text{ReLU}(W_1 x + b_1), \quad h_2 = \text{ReLU}(W_2 h_1 + b_2), \quad \hat{y} = W_3 h_2 + b_3 \]

```python
import torch.nn as nn
model = nn.Sequential(
    nn.Linear(input_dim, 64), nn.ReLU(),
    nn.Linear(64, 32), nn.ReLU(),
    nn.Linear(32, num_classes),
)
```

**Use when:** complex patterns, lots of data, structured tasks where boosting plateaus.

## Convolutional Neural Networks (CNNs)

Specialized for **grid-like data** (images). Uses **convolution** (sliding filters) to detect spatial patterns.

```python
import torch.nn as nn
conv = nn.Conv2d(in_channels=3, out_channels=32, kernel_size=3)
```

**Use when:** images, video frames, some audio (spectrograms).

**Famous architectures:** AlexNet, ResNet, EfficientNet, ConvNeXt.

## Recurrent Neural Networks (RNNs / LSTMs / GRUs)

Process sequences one step at a time, carrying hidden state.

\[ h_t = f(W h_{t-1} + U x_t) \]

**Mostly legacy now** — replaced by transformers for almost everything. Still useful for tiny embedded sequence tasks.

## Transformers

The architecture behind every modern LLM. Uses **self-attention** to let every token "see" every other token in the sequence in parallel.

\[ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right) V \]

**Use when:** language, code, multi-modal, anything sequential. Section 2 of the main path covers this in depth.

```python
from transformers import AutoModel, AutoTokenizer
tokenizer = AutoTokenizer.from_pretrained("bert-base-uncased")
model = AutoModel.from_pretrained("bert-base-uncased")
```

## Quick Decision Guide

| Data type | Start with |
|---|---|
| Tabular (structured) | **Gradient Boosting** (XGBoost) |
| Images | Pre-trained **CNN** or **Vision Transformer** |
| Text / Language | Pre-trained **LLM / Transformer** |
| Sequences (time series) | Gradient Boosting; Transformer if long-range |
| Need interpretability | Linear / Logistic Regression, shallow trees |
| Tiny dataset (<1000 rows) | Logistic Regression / Linear SVM |

## Other Notable Families (One-Liners)

- **Support Vector Machines (SVMs)** — find the maximum-margin separator. Strong on small high-dim datasets.
- **k-Nearest Neighbors (kNN)** — predict by majority of nearest neighbors. No training, slow at inference.
- **Naive Bayes** — probabilistic classifier assuming feature independence. Fast baseline for text.
- **Diffusion models** — generative models that learn to denoise. Powers Stable Diffusion, DALL-E.
- **GANs** — two networks competing (generator vs. discriminator). Largely replaced by diffusion for image generation.

## Takeaways

- **Always start with a linear baseline.**
- **Tabular data → gradient boosting** wins almost every time.
- **Images → CNNs / Vision Transformers** (use pre-trained).
- **Text → Transformers / LLMs** (use pre-trained).
- AI Engineers rarely train these from scratch — we **use pre-trained models** and fine-tune or prompt them.
