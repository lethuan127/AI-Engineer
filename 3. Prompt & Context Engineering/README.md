## Notes
- [Prompting Best Practices — What Changed When Models Got Strong](Prompting%20Best%20Practices%20—%20What%20Changed%20When%20Models%20Got%20Strong.md) — the 2026 reset: strong/reasoning models killed the old trick bag (CoT-on-everything, heavy few-shot, "you MUST!!!", self-consistency, prefill). Ends with a one-screen checklist.
- [Prompting Techniques Catalog — What Each One Is, and Whether It Still Earns Its Keep](Prompting%20Techniques%20Catalog%20—%20What%20Each%20One%20Is%20and%20Whether%20It%20Still%20Earns%20Its%20Keep.md) — the 18 named techniques from promptingguide.ai, each re-graded for 2026 reasoning models (✅ core / ⚠️ situational / ⛔ redundant / 🏗️ now architecture). The pattern: reasoning-elicitation tricks (CoT, self-consistency, ToT, graph) moved *into the model*; tooling/grounding tricks (RAG, ReAct, PAL, ART) moved *into the system*. Master table + four families + a which-technique-for-which-task decision table. Companion to the best-practices note.
- [Prompt Caching](prompt-caching.md) — the mechanics: prefix-match over exact bytes, KV-cache reuse, why early edits invalidate everything after, and how to order a prompt for cache hits.
- [Context Window Management — Eviction, Compaction & Memory](Context%20Window%20Management%20—%20Eviction%2C%20Compaction%20%26%20Memory.md) — the window is RAM, not disk: the five levers to stay under budget (don't-add, **isolate** via subagents, fetch-on-demand, **evict/page-out**, compact), eviction in depth (summarize-then-evict, RAM↔disk, LangChain "offloading"), and the Claude trio that implements it (memory tool persists, context editing evicts, retrieval restores). Plus eviction vs forgetting.
- [Context Compaction Theory — Selection, Generation, and the Budget Lower Bound](Context%20Compaction%20Theory%20—%20Selection%2C%20Generation%2C%20and%20the%20Budget%20Lower%20Bound.md) — the formal companion to the note above: compaction commits *before* the query, which makes it one-way communication, not retrieval. The two games (`SELECT` = truncation/pruning, `GEN` = summarization), where Codex/Claude Code/Gemini CLI/OpenCode/LangChain each land, the `Θ(log n)` proof that generation strictly beats selection, and the workloads (exact membership, set disjointness) that are **provably uncompactable** and must live in a tool. Plus the measured gap — Anthropic's compaction endpoint scoring at the random-guess line on set membership — and the two corollaries: compaction silently drops safety constraints (Governance Decay, 0% → 30% violation), and RL can be trained through the summarizer (CompactionRL).
- [Context as an Environment — Session State as an Executable Namespace](Context%20as%20an%20Environment%20—%20Session%20State%20as%20an%20Executable%20Namespace.md) — the systems answer to the compaction lower bounds: stop encoding. The session becomes an append-only Event Log plus a persistent Python kernel whose typed namespace survives across model calls, so tool outputs bind to variables and only printed projections enter the prompt. Eviction leaves an *addressed* landmark instead of prose, turning silent-omission failures into latency failures. Covers the three moves, the ACM/Scroll split (tools vs. a language for context editing), the reported `LOCA_256K` +37.4-point gap and how to read it, the five systems costs (sandbox on the critical path, session affinity, unbounded log), and a five-step steal-this-today list that starts with handle-returning tools.
