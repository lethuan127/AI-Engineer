## `100x-agent-hub` — Backend agent platform (2)

- `2026-06-22` fix(knowledge-base): stop stacking KB hints in MCP tool descriptions (#457)
  > on_list_tools mutated the shared registry Tool singletons in place
  > (tool.description = f"{kb_hint}\n\n{tool.description}"), so the change
  > persisted across requests and tenants. Under concurrent tools/list calls
  > the startswith() guard lost the race and multiple KB hints stacked onto
  > one description (and when it won, it leaked one KB's hint to another).
  >
  > Return per-request model_copy() copies instead and drop the now-useless
  > guard. The copy keeps the function reference, so tool calls still work;
  > only the displayed description changes per request.
