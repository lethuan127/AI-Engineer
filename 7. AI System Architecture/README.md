- [7.6. The Responses API as a Hosted Agent Loop](./7.6.%20The%20Responses%20API%20as%20a%20Hosted%20Agent%20Loop.md) — the third position on the axis `7.1`/`7.2` draw: an endpoint that looks like inference and behaves like a runtime (*"an agentic loop… within the span of one API request"*). Read through one question — **who owns the loop**. The item union replacing `messages` (a trace, not a chat log; `n` removed); why reasoning models score better here and cache better (~3% SWE-bench, 40–80% cache, and tool calling gated off Chat Completions from GPT-5.4); the **hosted-vs-client execution table** as the line that actually decides your architecture — hosted MCP means *OpenAI* originates the egress, outside every boundary [8.4](../8.%20AI%20Safety%20&%20Ethics/8.4.%20The%20Agent%20Containment%20Toolchain%20—%20Sandbox,%20Runtime,%20and%20Egress%20Proxy.md) tells you to build, and programmatic tool calling is a *hybrid* whose context saving the docs pointedly decline to quantify. Four state mechanisms and the retention asymmetry nobody reads (stored responses 30-day TTL, **conversation items none** — a compliance decision disguised as an ergonomic one), plus chaining that bills every prior token anyway. Three progressive-disclosure layers (tool search defers only the *parameter schema*; skills defer the `SKILL.md` body and run at **user** privilege; PTC defers intermediate output) versus compaction as the one mechanism that destroys information rather than deferring it — with the opposite pruning rules for server-side vs `/responses/compact`. Then the three escapes from single-response execution: `background` (the *only* real cancel), WebSocket `stream_id` lanes (~40% faster at 20+ tool calls, 60-min connections, in-memory continuation cache, and a documented cross-lane fork race), and multi-agent mode — no declarative agent list, six hosted coordination actions, and **aggregate-only usage**, which makes the ~15× token tax from [Multi-Agent Orchestration](../5.%20AI%20Agents%20&%20Tool%20Use/Multi-Agent%20Orchestration%20in%20Production%20—%20Topologies,%20Token%20Economics,%20and%20Coordination%20Failure.md) unmeasurable here. Closes on the trade stated precisely: you don't lose control, you swap *inherent* control for *granted* control — queues, error codes, and a socket that can drop — and on the observation that the happy path is specified while the failure path isn't.
